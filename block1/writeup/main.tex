\subsection{Introduction}

The goal of this section is to characterize the conditions under which the function defined by
\[ 
    \Z/n\Z \xrightarrow[x \mapsto ax+b]{} Z/n\Z
\]
is invertible.
That will give conditions for an \textit{affine cipher} to be a valid encryption method.

To do this we will need some basic number theory, and the following correspondence
between English letters and integers:
\begin{center}
\begin{tabular}{c|c|c|c|c|c}
    A & B & C & $\cdots$ & Y & Z  \\ \hline
    0 & 1 & 2 & $\cdots$ & 24 & 25
\end{tabular}
\end{center}

To motivate our study, we first prove the following fact.

\begin{proposition}
    Let $a,b \in \Z$ and consider the function $f: \Z \to \Z$ defined by 
    \[
        f(x) \coloneqq ax + b.
    \]
    Then $f$ is invertible if and only if $a=\pm1$.
\end{proposition}

\blue{
\begin{proof}
    Suppose $g(x) = cx + d$ and that $g$ is the inverse of $f$.
    That is, $f(g(x)) = x = g(f(x))$.....
\end{proof}
}

What is special about $a=\pm1$?
In this case, $a$ is what we call a \textbf{unit} of the ring $\Z$.
We will work to characterize the units of the ring $\Z/n\Z$ 
(and, while we're at it, define what a \textit{ring} even is).
To accomplish this we'll need to build a few ideas of number theory:
\begin{itemize}
    \item Greatest common divisor 
    \item Relative Primality
\end{itemize}




\subsection{Residues}

The symbol $\Z$ denotes the set
\[
    \{ \dots, -2, -1, 0, 1, 2, \dots\}
\]
of \textbf{integers} or \textbf{whole numbers}.
We define the set $\N$ of \textbf{natural numbers} to be the positive elements of $\Z$.

\begin{definition}
    Let $n$ be a positive integer.
    Define $\Z/n\Z$ to be the set 
    \[
        \{ [0], [1], \dots, [n-1] \}.
    \]
    Sometimes, instead of writing $[k]$ we will write $k\pmod{n}$
    or simply $k$ if there is no confusion.
\end{definition}

In some sense, we can think of $\Z/n\Z$ as a collection of all possible 
remainders upon division by $n$.
This idea is illustrated in the following fact.

\begin{proposition}[Division]\label{prop:div}
    Let $a,n \in \Z$ be two positive integers.
    There is exactly one pair $q,r\in\Z$ of positive integers satisfying 
    \begin{enumerate}
        \item $a = qn+r$,
        \item $0\leq r < n$.
    \end{enumerate}
\end{proposition}

In the case when $r=0$, we say $n|a$, pronounced \textbf{$n$ divides $a$}.\footnote{
    The symbol $|$ has an alternative pronunciation: ``guzinta.''
As in, ``$n$ guzinta $a$,'' or, ``$n$ goes into $a$.''}
We refer to $r$ as the remainder upon division by $n$, or 
the \textbf{residue of $a$ modulo $n$}.
We express this by writing $a \equiv r \pmod{n}$.

Two integers may have the same residue modulo $n$.
If $a \equiv r \pmod{n}$, then $a+n \equiv r \pmod{n}$ since 
\[ 
    a+n = (q+1)n + r.
\] 
A similar calculation shows that
\[
    r \equiv a+2n \equiv a+3n \equiv \cdots \pmod{n}.
\]
Thus we think of $r$ as ``representing'' the family $a+kn$ of integers, where $k$
ranges across all elements of $\Z$.
Depending on circumstance, we might write any of 
\[
    [a], \quad [a+n], \quad [a+2n], \quad \dots
\]



\begin{definition}[Modular arithmetic]
    Let $[a], [b] \in \Z/n\Z$.
    By Proposition~\ref{prop:div} we have the following two expressions:
    \begin{enumerate}
        \item $a+b = q_1 n + r_1$
        \item $ab = q_2 n + r_2$
    \end{enumerate}
    where $0\leq r_1,r_2 < n$.
    We define an additive and multiplicative operations on $\Z/n\Z$ by 
    \[  
        [a]+[b] \coloneq [r_1], \quad [a] \cdot [b] \coloneq [r_2].
    \]
\end{definition}

These algebraic operations are much nicer than their definition might first suggest.

\begin{proposition}[$\Z/n\Z$ is a ring]
    Let $[a],[b],[c] \in \Z/n\Z$:

    (Additive)
    \begin{enumerate}
        \item $[a]+[b] = [b]+[a]$
        \item $([a]+[b]) + [c] = [a] + ([b]+[c])$
        \item $[0]+[a] = [a] = [a]+[0]$
        \item $\forall [a], \exists [b]; [a]+[b] = [0]$
    \end{enumerate}

    (Multipliucative)
    \begin{enumerate}
        \item $[a]([b]+[c]) = [a][b] + [a][c]$
        \item $([a]+[b])[c] = [a][c] + [b][c]$
    \end{enumerate}
\end{proposition}

The operations defined above can be thought of as doing arithmetic on clocks of various sizes.

\begin{example}[$12$-hour clock]
    It is currently 11AM. 
    What time will it be in 6 hours?
    Well, $11+6 = 17$, and $17 = 1\cdot12 + 5$.
    Thus it will be $[11]+[17] = [5]$ o'clock.\

    This example may be extended to the very unreasonable case in which we give 
    every hour of the day its own unique name (i.e., a 24-hour clock).
    We're also doing modular arithmetic when we incorporate minutes, 
    except with a modulus of 60 instead of 12.
\end{example}




\begin{example}
    What is going on here?
    Are these numbers special in any way?
\begin{enumerate}
    \item $n=13$: $[7]+[9]+[2] = [18] = [5]$
    \item $n=13$: $[5]\cdot[6] = [30] = [4]$
    \item $n=13$: $[3]+[10] = [13] = [0]$
    
    \item $n=24$: $[8]+[11]+[1] = [20]$
    \item $n=24$: $[6]\cdot[4] = [24] = [0]$
\end{enumerate}
\end{example}






\subsection{Primes}

Now we return to the idea of divisibility.
\begin{definition}
    Let $a,b \in \Z$ be positive integers.
    If $a|b$ we say $b$ is a \textbf{multiple} of $a$, and that 
    $a$ is a \textbf{divisor} of $b$.
    Note that, for all integers $b$, we have $1|b$ and $b|b$.
    A positive integer $p$ is called \textbf{prime} if $p$ has exactly 
    two divisors: $1$ and $p$.
    A non-prime integer is called \textbf{composite}.
\end{definition}


Here are a few useful facts about prime numbers.

\begin{proposition}
\begin{enumerate}
    \item 
    Every integer greater than 1 is either prime, or is divisible by a prime.

    \item 
    Let $a,b,p\in\Z$ with $p$ prime.
    If $p|ab$ then either $p|a$ or $p|b$.

    \item 
    Let $a\in\Z$ be a positive integer.
    Then we may decompose $a$ as a product of primes as 
    \[
        a = p_1^{e_1} p_2^{e_2} \cdot \cdots \cdot p_k^{e_k}
    \]
    for some primes $p_i$.
    Moreover, this decomposition is unique, up to reordering.
\end{enumerate}
\end{proposition}


To illustrate, we give a few examples.

\begin{example}
\begin{enumerate}
    \item 13 is prime. So is 41.
    \item We can write $75 = 3 \cdot 5^2$.
    \item We can write $88 = 2^3 \cdot 11$.
    \item We can write $2007720 = 2^3 \cdot 3^3 \cdot 5^1 \cdot 11^1 \cdot 13^2$.
    \item We can write $2026 = 2 \cdot 1013$.
\end{enumerate}
\end{example}


We might now define the \textit{greatest common divisor} (GCD) of two integers 
to be the product of all primes (or powers of primes) dividing both integers.
This would give $\gcd(2026, 88) = 2$, 
it would give $\gcd(88, 20070020) = 2^3 \cdot 11 = 88$, et cetra.
A less concrete definition would be \textit{the greatest poisitive integer dividing both}.
But in order to hint at the mathematics underlying the algorithms we'll see shortly,
we give an even more abstract definition.
This, however, is not abstraction for abstraction's sake.

\begin{definition}[GCD]
    Let $a,b\in\Z$ be two positive integers.
    Define the set $\ess_{a,b}$ by 
    \[
        \ess_{a,b} \coloneq \{ xa + by : x,y \in\Z \}.
    \]
    We define the \textbf{greatest common divisor} of $a$ and $b$ to be the 
    smallest element of the set $\N \cap \ess_{a,b}$.
\end{definition}
